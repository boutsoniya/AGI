## 🧪 Benchmarks & Evaluation

We will add benchmarks next to experiments instead of measuring only whether code runs.

Examples:
- spatial reasoning
- multi-hop reasoning
- retrieval accuracy
- tool-use success
- planning success
- memory recall
- groundedness
- robustness
- latency / cost

## 🆕 New-Tech Radar

When something new appears:

**DISCOVER → READ → REPRODUCE → BENCHMARK → INTEGRATE / REJECT**

A new tool is not automatically a core dependency. The experiment decides.
