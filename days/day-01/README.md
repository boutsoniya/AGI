# Day 01 — Geometric Knowledge Representation

This folder contains the runnable Day 01 experiment.

## Run

From the repository root:

~~~bash
python days/day-01/geometric_knowledge.py
~~~

No external packages are required.

## Files

- geometric_knowledge.py — minimal geometric knowledge engine
- README.md — experiment notes

## Output

The program creates a tiny world of points and derives:

- Euclidean distance
- left/right relations
- above/below relations

The next step is to replace hard-coded derived checks with an explicit **rule layer**.
