DAY 13

Can an AI agent know when to stop?

A capable agent is not just one that keeps acting — it is one that recognises when another action is no longer worth the cost.

AI agentsdecision-making
BEFORE YOU READ

When should an agent stop searching?

Choose an answer before reading.

THE IDEA
Stopping is a decision. An agent needs to weigh the expected benefit of another step against its cost, uncertainty and possible harm. That can mean ending a search, asking a human, returning a partial answer, or refusing to take an irreversible action.
WHY IT MATTERS
Many agent demos reward persistence: more tool calls, longer plans, more attempts. But real tasks have budgets, deadlines and consequences. Knowing when to stop helps prevent wasted work, cascading errors and confident action on weak evidence.
TRY THIS
Give an agent a task with a limited tool-call budget. Test three policies: stop after a fixed number of steps, stop when confidence crosses a threshold, and stop when the expected value of another step is lower than its cost. Compare task success, tool calls, unsupported claims and harmful actions.
INTERACTIVE LAB · HALLUCINATION CHECK

Can confidence predict truth?

For each claim, set how confident you are that it is true. Then reveal the result. The goal is not to get every answer right — it is to notice whether confidence tracks reality.

INTERACTIVE LAB · WORLD MODEL

Predict the next state

The agent is in a tiny grid world. Before each action, the world model predicts where the agent should end up. Move through the environment and watch prediction become useful for planning.

Choose an action. The model will predict the next state before the move.
INTERACTIVE LAB · TOOL ROUTER

Should the agent use a tool?

A tool-using agent should not call tools just because they exist. For each task, choose the smallest useful action: answer directly, calculate, or look something up.

WHERE IT BREAKS
A stopping rule can quit too early when confidence is poorly calibrated, or continue too long when the agent mistakes activity for progress. Thresholds also need to change with the stakes of the task.
TAKEAWAYGood autonomy includes a well-designed stopping rule.
