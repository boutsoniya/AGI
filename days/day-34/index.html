What should an AI remember—and what should it forget?

Memory makes an AI more useful across time, but storing everything can be a privacy and reliability problem. The design question is what deserves to persist.

AI memorypersonalisationprivacy
THE IDEA

A useful AI memory is not a transcript of everything it has seen. It is a carefully selected set of information that may help future interactions: stable preferences, ongoing goals, relevant project context or a decision the user explicitly wants carried forward. Memory needs a lifecycle—what gets saved, why it is useful, how it can be corrected, when it expires and how it is deleted. Retrieval matters too: even a correct memory can be harmful if it is surfaced in the wrong context.

WHY IT MATTERS

Without memory, people repeatedly explain their preferences and projects. With indiscriminate memory, the system may retain sensitive, outdated or irrelevant details and use them unexpectedly. Good memory design balances continuity with user control, relevance and data minimisation. A system should be able to distinguish a temporary fact from a durable preference, and uncertainty from something the user confirmed.

TRY THIS

Try a simple memory policy for an assistant: save only facts that are useful in future sessions, avoid sensitive information unless necessary and explicitly requested, attach a reason or timestamp, and let the user review or correct saved items. Compare how well it helps with a recurring task after saving a few preferences versus storing an entire conversation.

WHERE IT BREAKS

Memory can become stale, overgeneralise from one interaction, or retrieve a detail that is irrelevant or uncomfortable. A preference may change; a one-time request is not a permanent trait. Retrieval errors and unclear controls can undermine trust. The system should treat memory as fallible context—not unquestionable truth—and provide a clear way to update or remove it.

TAKEAWAY

Good AI memory is selective, useful, revisable and under the user's control.

BEFORE YOU READ

Which memory policy is better for a personal AI?

A. Store every conversation forever

B. Save relevant, user-controllable facts with review and deletion

Answer: B. Right. Selective memory with controls supports continuity without treating every interaction as permanently important.
